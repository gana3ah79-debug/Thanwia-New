# رحلة الثانوية — Android

مشروع Android جاهز للبناء، مبني على نسخة رحلة الثانوية التي تتضمن اختبارات AI (اختيار من متعدد ومقالي).

- Android 6.0+ (API 23)
- موبايل وتابلت
- Supabase + AI عبر Edge Function
- لا توجد مفاتيح API سرية داخل التطبيق

## البناء
افتح المشروع في Android Studio ثم Build > Generate App Bundle / APK > Generate APK.

## ملفات المشروع
المشروع موجود داخل مجلد `android_project`.
